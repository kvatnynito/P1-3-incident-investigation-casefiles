# Attack Scenarios

The canonical ordered scenario list, numbered execution steps, sequencing rules, and completion gate are maintained in [`plan.md`](plan.md). Individual ground truth, queries, timelines, findings, and dispositions belong in the matching folder under [`../cases/`](../cases/).

Scenario families currently include authentication attacks, PowerShell/process behavior, DNS and outbound-network anomalies, vulnerability management, suspicious-file simulation, privilege escalation, persistence, lateral movement, and the separately planned DVWA web-attack case.
